# 단타 종목 선별 AI (한국 · 미국)

장 마감 데이터로 **다음 거래일 단타 후보**를 골라 **승률 · 진입가 · 익절가 · 손절가**를 정해주고,
장중에는 **지금 강한 종목**을 스캔합니다. GitHub Actions로 **PC 없이 자동 실행**되어
결과가 **텔레그램으로 휴대폰에 바로** 오고, **`https://minho0407.github.io/daytrade/`** 페이지에도 올라갑니다.

## 📱 자동 실행 + 휴대폰 알림 설정 (PC 필요 없음)

1. **텔레그램 봇 만들기**
   - 텔레그램에서 `@BotFather` 검색 → `/newbot` → 이름 정하면 **봇 토큰**을 줍니다
   - 만든 봇에게 아무 메시지나 하나 보냄
   - 브라우저에서 `https://api.telegram.org/bot<봇토큰>/getUpdates` 열기 → `"chat":{"id": 숫자}` 가 **채팅 ID**
2. **GitHub에 비밀값 등록**: 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - `TELEGRAM_BOT_TOKEN` = 봇 토큰
   - `TELEGRAM_CHAT_ID` = 채팅 ID
3. **이 작업 브랜치를 `main`에 합치기** (GitHub 예약 실행은 기본 브랜치에서만 동작)
4. **시험 실행**: 저장소 → Actions → `daytrade-ai` → Run workflow → `kr` 선택
   - 1~5분 뒤 텔레그램 메시지 도착 + `/daytrade/` 페이지 갱신

| 시각 (한국) | 작업 |
|---|---|
| 평일 15:50 | 🇰🇷 내일 후보 (당일 단타 + 2일 스윙) |
| 평일 06:30 | 🇺🇸 오늘 밤 후보 (미국 장 마감 후) |
| 평일 09:40 | 🇰🇷 장중 강세 종목 스캔 |
| 평일 00:00 | 🇺🇸 장중 강세 종목 스캔 |

- 휴장일엔 최신 데이터가 오늘 날짜가 아니면 자동으로 전송을 건너뜁니다.
- GitHub 예약 실행은 서버가 붐비면 5~30분 늦을 수 있습니다. 시간은 `.github/workflows/daytrade.yml`에서 바꿀 수 있습니다.
- 공개 저장소라면 `/daytrade/` 페이지는 누구나 볼 수 있습니다 (검색엔진 노출만 막아둠). 비공개로 받고 싶으면 텔레그램만 쓰세요.
- 공개 저장소의 Actions는 무료입니다.

### 텔레그램 메시지 예시

```
📈 [KR] 당일 단타 후보 (11/26 마감 기준)
최근 검증: 상위5 승률 54%, 평균 +0.21% (전체종목 -0.18%)

1. 000000.KQ 예시종목
   승률 58% · 기대 +0.42%
   진입 시가 (≤182,300 일 때만, 기준 179,500)
   익절 184,900 (+3.0%) · 손절 176,300 (-1.8%)
```
(숫자는 형식 예시입니다)

| 명령 | 하는 일 |
|---|---|
| `backtest` | 과거 데이터로 "이 모델대로 샀다면?"을 워크포워드 방식으로 검증 |
| `pick` | 오늘 장 마감 기준, 다음 거래일 매수 후보 Top N |
| `scan` | 장중 5분봉으로 거래량 급증·VWAP 위·시가범위 돌파 종목 점수화 |

## 설치

```bash
cd daytrade-ai
pip install -r requirements.txt
```

## 사용법

```bash
# 1) 먼저 검증부터: 이 전략이 과거에 통했는지
python main.py backtest --market kr --mode day                 # 한국, 당일 단타
python main.py backtest --market us --mode swing --horizon 2   # 미국, 2일 보유

# 2) 장 마감 후: 내일 살 후보 + 승률/진입/익절/손절
python main.py pick --market kr --mode day --top 5
python main.py pick --market kr --mode day --min-win 0.55   # 승률 55% 이상만
python main.py pick --market kr --mode day --notify         # 텔레그램 전송 (환경변수 필요)

# 3) 장중: 지금 뜨는 종목
python main.py scan --market kr

# 네트워크 없이 동작만 시험
python main.py backtest --demo
```

### 두 가지 단타 모드

- `--mode day` : 다음날 **시가 매수 → 같은 날 종가 매도** (당일 청산)
- `--mode swing --horizon 1|2|3` : 다음날 **시가 매수 → N거래일째 종가 매도**

### 주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--top` | 5 | 하루에 고를 종목 수 |
| `--tp` / `--sl` | day 1.0/0.6, swing 1.5/1.0 | 익절·손절 거리 (ATR 배수) |
| `--max-gap` | 4% | 시가 갭상승이 이 값(또는 익절폭 절반)을 넘으면 진입 포기 |
| `--min-win` | 없음 | 과거 승률이 이 값 미만인 종목 제외 |
| `--cost` | kr 0.3%, us 0.1% | 왕복 비용 (수수료+세금+슬리피지) |
| `--universe` | 300 | 시총 상위 몇 종목을 볼지 |
| `--min-turnover` | kr 50억, us 2천만$ | 20일 평균 거래대금 하한 (잡주 제외) |
| `--period` | 4y | 학습 기간 |
| `--tickers` | - | 직접 만든 종목 목록 파일 (예: `005930.KS AAPL ...`) |

결과는 `output/` 폴더에 CSV로 저장됩니다.

## 어떻게 동작하나

1. **데이터**: yfinance로 일봉(한국은 `.KS`/`.KQ` 티커), 종목 목록은 FinanceDataReader로 시총 상위 추출
2. **특징 29개** (`features.py`): 1~20일 수익률, 갭, 캔들 몸통/꼬리, 거래량 배수, 거래대금, ATR, RSI, 이동평균 이격, 20/60일 고점 돌파, 연속 상승일, 같은 날 종목 간 순위, 시장 전체 흐름
3. **정답**: 다음날 시가에 샀을 때의 실제 수익률 ÷ ATR (위험 대비 수익)
   - "3% 오를 확률" 같은 분류는 변동성만 큰 종목을 고르는 함정이 있어서 쓰지 않습니다
4. **모델**: LightGBM 회귀. 점수가 높은 순으로 Top N 선택
5. **매매 규칙**: 다음날 시가 매수 → 익절가(+tp×ATR) 또는 손절가(−sl×ATR) 닿으면 청산, 아니면 기간 끝 종가 청산.
   일봉 한 개 안에서 둘 다 닿으면 **손절 먼저**로 보수적으로 계산
6. **승률**: 모델의 주관적 확률이 아니라, **과거 검증 기간에 비슷한 순위였던 종목이 위 규칙대로 실제로 이긴 비율**
7. **검증**: 워크포워드 — 항상 과거로만 학습하고 그 뒤 20일을 예측, 반복. 학습/테스트 사이에 보유기간만큼 간격을 둬서 미래 정보가 새지 않게 함

### 백테스트 결과 읽는 법

- **비교: 전체종목 평균** 보다 **평균수익**이 확실히 높아야 의미가 있습니다
- **점수 10분위별 실제 수익**이 0→9로 갈수록 커지면 모델이 순서를 맞추고 있다는 뜻
- **순위상관(IC)**: 0.02~0.05만 꾸준히 나와도 일봉 단타에선 괜찮은 편, 0 근처면 쓸모 없음
- 비용차감 평균수익이 음수면 **실전에서 쓰지 마세요**

## 주의

- 투자 판단의 참고용입니다. 수익을 보장하지 않으며 손실 책임은 본인에게 있습니다.
- 백테스트 성과가 미래 성과를 의미하지 않습니다. 특히 파라미터를 여러 번 바꿔가며 가장 좋은 결과만 고르면 과최적화됩니다.
- yfinance는 비공식 데이터라 가끔 누락·지연이 있습니다. 한국 분봉은 지연 데이터일 수 있어 장중 실매매엔 증권사 API(키움, 한국투자증권 KIS 등)를 권장합니다.
- 손절/익절가는 ATR 기반 단순 참고치입니다.
- 현재 종목 목록 기준으로 과거를 검증하므로 상장폐지 종목이 빠져 있어(생존 편향) 백테스트가 실제보다 좋게 나올 수 있습니다.
